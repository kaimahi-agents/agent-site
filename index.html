Unit tests for your agent's prompt.

Run the same tests on a second model and see where they differ before you switch.

Tool calls recorded once

The first run calls the real tool and saves the result. Later runs replay it, so tests stay fast and repeatable.

Install

You need the Copilot app and CLI and a signed-in Copilot account. On Windows, kmx runs in WSL.

1. In WSL (or a macOS terminal), install kmx

curl -fsSL https://raw.githubusercontent.com/kaimahi-agents/kaimahi/[VERSION]/install.sh | sudo sh -s -- --version=[VERSION]

2. Add the plugin to Copilot

copilot plugin marketplace add kaimahi-agents/kaimahi
copilot plugin install kmx-agent-builder@kmx-plugins

3. In the Copilot app, ask for an agent

Create an agent that turns merged pull request titles into release notes.
